# Rețeaua neuronală



## O rețea neuronală este un model matematico-informatic inspirat de modul în care funcționează creierul uman. Este folosită pentru a învăța tipare din date — fie că vorbim de imagini, text, sunet sau valori numerice.

Iată explicația pe scurt, într-un stil clar:

## 🧠 Ce este o rețea neuronală

### O rețea neuronală este formată din straturi de neuroni artificiali (noduri). Fiecare neuron primește valori, le procesează printr-o funcție și transmite rezultatul mai departe.

### Structura de bază este:

Input layer – primește datele (de exemplu pixelii unei imagini).

Hidden layers – unde are loc transformarea și „înțelegerea” datelor.

Output layer – rezultatul modelului (o clasificare, o predicție etc.).

## 🔗 Cum „învață” o rețea neuronală

Prin două mecanisme:

### 1. Propagare înainte (forward pass)

Datele intră în rețea, sunt combinate cu ponderi (weights) și trec de la un strat la altul.

### 2. Învățare prin corectare (backpropagation)

Modelul își compară predicția cu rezultatul real → calculează o eroare → ajustează ponderile pentru a reduce eroarea.

Cu cât trece prin mai multe exemple, cu atât devine mai bun.

## 🔍 Tipuri de rețele neuronale

### MLP (perceptron multistrat) — varianta de bază.

### CNN (Convolutional Neural Network) — pentru imagini, viziune computerizată.

### RNN / LSTM / GRU — pentru date secvențiale (text, audio, time series).

### Transformers — arhitecturi moderne pentru NLP, viziune etc. (de exemplu GPT, BERT).

### GANs — generatoare de imagini, video, audio.
